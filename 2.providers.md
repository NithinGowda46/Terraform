# Terraform Providers

A **provider** is a Terraform plugin that lets Terraform communicate with an external platform or service. Providers define the resource types and data sources Terraform can manage. For example, the AWS provider lets Terraform manage AWS resources, while the `local` provider can manage files on your computer.

## Declaring a provider requirement

The `terraform` block can specify which providers the configuration needs and which versions are allowed:

```hcl
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 6.0"
    }
  }
}
```

- `source` identifies the provider package to download from the Terraform Registry.
- `version` constrains which provider versions Terraform may use. `~> 6.0` allows compatible versions in the 6.x series.

Run `terraform init` in the configuration directory to download the required provider and initialize the working directory.

## Configuring a provider

A `provider` block supplies settings the provider needs, such as the AWS region:

```hcl
provider "aws" {
  region = "ap-south-1"
}
```

The provider configuration is then used by AWS resources in that Terraform configuration. Credentials are typically supplied through the AWS CLI or environment, rather than written directly into the configuration.
