# Terraform Basics

Terraform configuration is written in `.tf` files. It describes the resources Terraform should create or manage.

## Blocks

A **block** is a section of Terraform configuration. It begins with a block type and contains its settings inside curly braces `{ }`.

## Resources

A **resource block** tells Terraform what to create or manage. It has a resource type and a resource name:

- The **resource type** identifies what kind of resource Terraform manages.
- The **resource name** identifies that resource in your configuration.

## Arguments

**Arguments** are settings inside a block. They use the format `name = value` and provide details about the resource.

## Example

```hcl
resource "local_file" "my_file" {
  filename = "automate.txt"
  content  = "best content"
}
```

Here, `resource` is the block type, `local_file` is the resource type, and `my_file` is the resource name. `filename` and `content` are arguments. Terraform will create `automate.txt` containing `best content`.

## Terraform commands

Run these commands from the directory containing the `.tf` file:

```sh
terraform init
```

Initializes the working directory and downloads the required provider.

```sh
terraform validate
```

Checks the configuration for errors.

```sh
terraform plan
```

Previews the changes Terraform plans to make.

```sh
terraform apply
```

Applies the planned changes. Review the plan and type `yes` when prompted.

To remove the file managed by Terraform, run:

```sh
terraform destroy
```
